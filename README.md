# เงาสะท้อน — สมุดบันทึกส่วนตัว

แอพจดบันทึกส่วนตัว 6 โหมด (Reflect, Idea, Thought, Today Task, Health, Review)
เป็น PWA (Progressive Web App) ไฟล์เดียวจบ ไม่มี build step ไม่มี backend ไม่มีบัญชีผู้ใช้

**ข้อมูลทุกอย่างเก็บอยู่ในเครื่องที่เปิดแอพเท่านั้น** (`localStorage`) ไม่มีการส่งข้อมูลออกจากเครื่องไปที่ไหนเลย

**ใช้งานออฟไลน์ได้เต็มรูปแบบ** — มี `service-worker.js` แคชทุกไฟล์ของแอพไว้ตั้งแต่เปิดครั้งแรก
หลังจากนั้นเปิดใช้งานได้แม้ไม่มีเน็ตเลย (ทดสอบแล้วโดยปิดเซิร์ฟเวอร์ทั้งหมดแล้วรีโหลด แอพยังทำงานได้ปกติ)

## โครงสร้างไฟล์

- `index.html` — ตัวแอพทั้งหมด (HTML/CSS/JS อยู่ในไฟล์เดียว)
- `manifest.json` — ชื่อแอพ ไอคอน สีธีม สำหรับตอนติดตั้งขึ้นหน้าจอ
- `service-worker.js` — แคชไฟล์ไว้ให้ใช้งานออฟไลน์ได้
- `icons/` — ไอคอนแอพ 3 ขนาด (สร้างจาก `gen-icons.js`)
- `gen-icons.js` — สคริปต์ที่ใช้สร้างไอคอน (รันด้วย `node gen-icons.js` ถ้าอยากปรับดีไซน์ไอคอนใหม่)

## Deploy ขึ้น GitHub Pages ของตัวเอง

```bash
cd journal-app
git add -A
git commit -m "เงาสะท้อน v1"
gh repo create journal-app --private --source=. --push
gh api -X POST repos/:owner/:repo/pages -f "source[branch]=main" -f "source[path]=/"
```

(รอสักครู่ให้ GitHub build เสร็จ) จะได้ลิงก์แบบ `https://<username>.github.io/journal-app/`
เปิดลิงก์นั้นด้วย **Safari** บน iPhone แล้วกด **Share → Add to Home Screen**
จะได้แอพขึ้นหน้าจอ Home ใช้งานออฟไลน์ได้เต็มรูปแบบ ไม่เกี่ยวกับ Claude หรือบัญชีใด ๆ อีกต่อไป

ถ้าไม่มี `gh` CLI ติดตั้งไว้ ให้สร้าง repo จากหน้าเว็บ github.com แทน แล้ว push ตามปกติ
จากนั้นเปิด **Settings → Pages** ของ repo แล้วเลือก branch `main` / โฟลเดอร์ `/ (root)`

## อัปเดตแอพในอนาคต (patch)

แก้โค้ดใน `index.html` (หรือไฟล์อื่น) แล้ว:

```bash
git add -A
git commit -m "อธิบายว่าแก้อะไร"
git push
```

GitHub Pages จะ build และอัปเดตเวอร์ชันบนลิงก์เดิมให้อัตโนมัติภายในไม่กี่นาที
เปิดแอพใหม่อีกครั้ง (ต้องมีเน็ตตอนเปิดครั้งแรกหลังอัปเดต) service worker จะดึงเวอร์ชันใหม่มาแคชแทนของเก่า

## ทดสอบในเครื่องก่อน deploy

```bash
npx serve journal-app -l 5173
```

เปิด http://localhost:5173 ในเบราว์เซอร์เพื่อดูก่อนได้

## ข้อมูล & ความเป็นส่วนตัว

- ข้อมูลทั้งหมดอยู่ใน `localStorage` ของเบราว์เซอร์/อุปกรณ์ที่ใช้งานเท่านั้น
- ไม่มี PIN ล็อก — เข้าแอพแล้วใช้งานได้ทันที
- มีปุ่ม "สำรองข้อมูล" ที่หน้าแรก (ไอคอนดาวน์โหลดมุมขวาบน) ให้คัดลอกหรือดาวน์โหลดข้อมูลเป็นไฟล์ JSON
  เก็บไว้กันลืม และนำกลับเข้ามาได้จากหน้าเดียวกัน
- ถ้าเปลี่ยนเครื่อง/ล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหายไป ต้องใช้ไฟล์สำรองที่คัดลอกไว้นำเข้าใหม่
